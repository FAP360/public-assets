# FAP360 Public Assets

Public static assets used by FAP360 projects and integrations, including Zoho Creator, HTML and JavaScript projects.

## Structure

- `logos/` – logos grouped by brand or project
- `icons/` – reusable icons
- `images/` – general images and backgrounds
- `css/` – shared stylesheets
- `js/` – shared JavaScript files

## File naming

Use lowercase English filenames with hyphens. Avoid spaces and Swedish characters such as å, ä and ö.

Examples:

- `abt-logo.svg`
- `abt-logo-white.svg`
- `fap360-icon.svg`
- `document-icon.svg`
- `quote-background.png`

## Important

This repository is public. Do not store credentials, API keys, secrets or confidential material here.
